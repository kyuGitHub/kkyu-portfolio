PPT 화면설계서 대신
동작하는 화면을 넘기기

PM이 요구사항을 넣으면 디자인 시스템 규격대로 동작하는 어드민 화면을 AI가 만들고, PM은 클릭으로 고친 뒤 화면정의서와 함께 개발자에게 넘깁니다. 문제 정의, PRD, 구현까지 약 4주 동안 직접 진행했습니다.

역할
문제 정의 · PRD · 구현 지휘
기간
2026.10 · 약 4주
상태
파일럿 준비
목표
화면당 30분 이내

문제

어드민 화면 하나가 현업 → PM → 디자이너 → 퍼블리셔 → 개발자 5단계를 거쳤고, PM이 PPT로 목업을 그리는 단계가 병목이었습니다. 화면 하나에 30분~1시간, 정보가 많으면 2~3시간이 걸렸습니다.

  • 상태·권한별 케이스를 미리 볼 시간이 없었습니다.
  • 개발 중에 항목·버튼 추가 요청이 화면마다 생겨 수정 개발로 돌아갔습니다.
  • 전달 단계마다 기획 의도가 조금씩 빠졌습니다.

PM 인터뷰(5라운드, 25문항)로 이 병목을 확인했습니다.

만든 것

AI를 제약된 시스템으로 설계

  • AI가 자유롭게 HTML을 쓰지 않고 정해진 JSON 스키마만 출력하게 했습니다. 디자인 규격을 강제할 수 있고, 같은 입력에서 결과가 흔들리는 것도 줄었습니다.
  • 시스템 프롬프트와 참고 화면은 프롬프트 캐싱으로 재사용하고, 사용자별 일일 한도와 호출별 비용 로그를 둡니다. 화면당 비용은 약 350~650원으로 추정했습니다.
  • 실제 고객 정보는 쓰지 않고 샘플 데이터를 자동으로 채웁니다.

React 19 · TypeScript · Vite · Supabase · Vercel · Anthropic SDK

배운 점

AI에게 자유를 줄수록 결과를 믿기 어려웠습니다. 출력 형식을 스키마로 묶고 검증과 재시도를 붙이자, 현업에 넘길 수 있는 수준으로 결과가 안정됐습니다.
